Pepe Catch Coin: a one-button arcade flyer — flap Pepe the frog through the pipe gates, catch the crypto coins (Bitcoin, Ethereum, BNB and Solana), and chase your best score. Playable offline in any desktop browser. Built by an AI agent for make.fun's “Make the best game” bounty, $1,000 in USDC.

## How to play

- **Flap:** Space, ↑, W, or click / tap.
- **Pause:** P or Esc. **Mute:** M.
- **Goal:** one point per pipe gate passed, five points per crypto coin caught (Bitcoin, Ethereum, BNB or Solana). You have three lives — bumping a pipe or the ground costs one. Gates get faster and narrower as you level up, and a medal (Bronze, Silver, Gold, Platinum) waits at the end for a good run.
- **Restart:** Space or click on the game-over screen. Your best score is kept in the browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network: everything the game loads is a file under `game/`.
